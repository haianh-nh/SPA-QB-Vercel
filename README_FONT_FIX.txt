FONT FIX

Đã sửa lỗi font/hiển thị tiếng Việt:
- Thêm meta charset UTF-8 nếu thiếu.
- Dùng font hệ thống hỗ trợ tiếng Việt tốt hơn.
- Bỏ letter-spacing ở label/button/input/select.
- Không ép uppercase các label tiếng Việt.
- Đổi label hiển thị dễ đọc hơn:
  EMAIL -> Email
  PASSWORD -> Password
  NHẬP LẠI PASSWORD -> Nhập lại password
  MODULE -> Module
  CATEGORY / CHAPTER -> Category / Chapter
  SỐ CÂU HỎI -> Số câu hỏi

Giữ nguyên:
- Bank câu hỏi
- payOS
- Supabase Auth
- Confirm password khi đăng ký
- Recovery password
